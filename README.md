# UI Catalog — компоненты и блоки

Каталог интерфейсных компонентов и готовых блоков с просмотром реализации и визуальным предпросмотром.

## Возможности

- Разделы компонентов и блоков.
- Предпросмотр шаблонов и выдача их ресурсов.
- Подсветка исходников и типизированная модель каталога.

## Инженерные акценты

- Разработка внутреннего инструмента для ускорения сборки сайтов.
- Систематизация повторно используемых UI-решений.
- Связь визуального результата, исходного кода и метаданных компонента.

## Стек

React, Next.js, TypeScript, Vitest, Swiper, Sass.

## Навигация по коду

- [src/](src/) — исходный код.
- [templates/](templates/) — шаблоны и блоки.

## Разработка

Инструменты: pnpm.

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm lint
```
